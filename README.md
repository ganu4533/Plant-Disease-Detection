# 🌱 Plant Disease Detection and Solution

An AI-powered Plant Disease Detection System that identifies plant diseases from leaf images using Deep Learning and provides possible treatment solutions for farmers.

---

## 📌 Project Overview

Plant diseases can significantly reduce crop productivity and quality. This project uses Convolutional Neural Networks (CNN) and TensorFlow to detect plant diseases from images of leaves.

The system helps farmers by:
- Detecting diseases early
- Providing disease information
- Suggesting possible treatment solutions
- Offering a simple Android-based interface

---

## ✨ Features

✅ Plant disease detection using Deep Learning
